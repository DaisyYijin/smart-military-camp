# 数智军营人员管理系统

面向 **Windows 7+ / Linux(x86 与 arm64 麒麟)** 的内网离线人员管理系统。
**免安装、双击即用、浏览器访问**，数据全部保存在本机，支持单机或局域网多用户部署。

## 技术架构

```
┌──────────────────────┐   HTTP/JSON(Token)   ┌───────────────────────────┐
│  浏览器(任意电脑)    │ ────────────────────▶ │  单文件服务端(内嵌网页端) │
│  Win7/10/麒麟 自带    │                       │  Spring Boot + SQLite     │
│  浏览器即可,零安装    │                       │  双击运行:向导→托盘→浏览器│
└──────────────────────┘                       └───────────────────────────┘
                                               数据:data/personnel.db + photos/
```

| 组件 | 技术 | 说明 |
|---|---|---|
| 服务端 | Spring Boot 2.7 + SQLite(JDK8,Win7/麒麟兼容) | 单 jar,含启动向导/托盘/网页端 |
| 网页端 | 原生 HTML/JS/CSS,**零第三方依赖** | 离线内网可用,不做 npm 构建 |
| 数据库 | SQLite 默认,可选 MySQL / PostgreSQL / 金仓 / 达梦 | 启动向导"数据库设置"可切换外部库,驱动放 `lib/` 自动加载 |
| 测试 | JUnit 5 后端 857 项 + Node 前端 274 项 | 打包脚本自带全量测试门禁 |

> 旧版 Swing 客户端与 systemd 部署脚本已在清理时移除,如需找回见 git 历史(存档提交 `539f748`)。

## 核心功能

### 人员与组织
- **人员档案**:30+ 字段(基本信息/军衔职级/政治面貌/学历/身份证/联系方式/家庭/住房/私家车/驾驶证等档案子表),照片裁剪上传,变动轨迹(入职/调动/退役)时间线
- **批量操作**:勾选后批量删除(可撤销 30 天)、批量编辑(单位/状态/类别/政治面貌/婚姻/驻地等字段一键批量修改)
- **单位树管理**:任意层级组织树,拖拽排序,人员按单位含下级统计,编制与实际在岗双口径
- **数据字典**:军衔(晋升年限规则)/状态/类别/政治面貌/休假类型等下拉项全部可自定义,业务分组(如人员类别下挂专业技术文职等子类)
- **军衔晋升提醒**:按军衔晋升年限规则(列兵 1 年→上等兵→下士 3 年→中士 3 年→二级上士…)自动推算,支持"相当入伍年月"折算(大学生士兵兵龄认定),到期自动出现在近期事件

### 考勤与在位
- **在外登记**:临时出差/学习/培训等离开单位登记(事由/离开日期/预计返回),可延期;到期未归自动提醒;人员状态自动联动(在位↔出差/培训),支持预登记(未到离开日期不生效)
- **补课登记**:按单日或起止区间查看全员在位情况(休假/在外/在位三源推断),18 列自定义显示(勾选显隐+拖宽记忆),在位率统计卡,按筛选导出 Excel
- **休假管理**:休假计划(年度安排)+休假登记(实际记录),按月统计各人员重叠天数,可导出;自动状态联动(休假中自动变更状态,销假恢复)

### 业务模块
- **装备管理**:装备台账、状态流转、历史故障记录
- **物资管理**:库存台账、库存预警、出入库
- **车辆管理**:车辆台账、保险/年审到期提醒
- **物品借还**:借出归还登记、超期提醒
- **手机设备**:手机台账(串号/IMEI)、使用状态管理
- **体能考核**:考核项目矩阵、宽行 Excel 导入(一人一行、项目为列)、汇总视图、体能标准维护
- **军事考核**:考核方案树(方案→科目分组→科目)、成绩录入、方案级导入导出
- **双争评比**:四季度评比记录、六字段表单(人员查找/身份证带出)、年度视图、专用 Excel 导入导出
- **年度考评**:年度考评记录,与双争同构

### 协同与系统
- **组织建设**:用户自建组织(党支部/团支部/风气监督员/安全员等任意组织),tab 式分类管理,成员表(序号/姓名/身份证+自定义列),表头可关联人员档案字段,拖拽排序,名册下载(公文体 Excel:方正小标宋/黑体/仿宋)
- **消息通知**:站内信(单发/群发/全员),顶栏铃铛未读角标 30 秒轮询,消息中心(已读/全部已读/删除)
- **审批工作流**:休假/在外等申请提交→管理员待审批→通过自动写入对应模块(失败整体回滚)
- **备份恢复**:17 模块全覆盖(42 张表)手动备份(按模块勾选)+ 自动定时备份;备份包上传校验(完整性/版本兼容);恢复隔离(按模块独立,旧版本备份自动豁免后加表);照片随包
- **数据上报**:下级单位导出数据包(人员+子表+休假+体能+军事+在外+补课)→ 上级接收(身份证去重/业务键幂等/版本冲突检测,下级为准替换)
- **统计报表**:仪表盘可配置(拖拽排序/尺寸切换/图表更换),总人数/单位人数/性别状态分布/入伍趋势/休假类型/近期事件(证件/军衔/车辆/物资/借还/生日/休假/党务/在外,30/90/365 天窗口)
- **操作日志**:登录/登出/增删改/导入导出/备份全记录,关键词+操作类型+日期组合筛选
- **系统设置**:站点外观(名称/LOGO/favicon/主题色)、备份设置、账号管理(多管理员+单位数据权限范围)

### 交互细节
- Excel 导入:文件选择+**拖拽到页面直接导入**;下载模板;进度弹窗;部分失败逐行报告
- 花名册下载:字段勾选弹窗(55+ 字段胶囊选择),按需生成
- 列宽拖拽记忆(按视图+表头 localStorage)
- 日期选择:手输+日历双模式,键盘导航,起止区间筛选
- 全局搜索/筛选:每模块独立筛选面板,组合查询
- 减动效(Prefers-Reduced-Motion)与老旧浏览器兼容

## 快速开始

### 方式一:发行包(推荐给最终用户)
到 [Releases](https://github.com/DaisyYijin/smart-military-camp/releases) 下载对应平台包(或本地 `packaging/dist/<构建编号>/`,`bash packaging/build-release.sh` 生成,含 SHA256SUMS):
- `数智军营-win64.zip`:Windows 7/10/11(64 位)→ 解压 → 双击 `启动系统.bat`
- `数智军营-linux-x64.tar.gz`:Ubuntu/CentOS/统信等 x86 → 解压 → `./start.sh`
- `数智军营-linux-arm64.tar.gz`:麒麟/鲲鹏/飞腾 arm64 → 解压 → `./start.sh`
- `数智军营-linux.tar.gz`:轻量通用包(不内置 JRE,要求系统已装 Java8)
- 详见包内《使用说明.txt / README.txt》

### 方式二:源码开发与测试(仓库 `.tools/` 内自带 JDK8 + Maven)
**日常开发直接双击根目录的 `开发运行.bat`**:自动编译最新代码 → 以开发模式在本项目目录启动(数据用项目 `data/`),**不需要打包解压**。

开发模式的热更新规则:
- **改前端**(HTML/CSS/JS):保存后浏览器按 F5 立即生效,**不用重启**
- **改后端**(Java):重新双击 `开发运行.bat`(约 20 秒)

代码静态审查(SpotBugs,已配置在 `personnel-server/pom.xml`):
- 双击根目录 **`代码审查.bat`** → 全量报告(HTML)在 `personnel-server/target/spotbugs.html`
- `mvn verify` 会在出现**高置信度缺陷**时构建失败,防止新增高危问题;`开发运行.bat` 与打包脚本走 `package`/`test`,不受影响
- 首次运行需联网下载插件(已缓存到本机 Maven 仓库,之后离线可用)

测试满意后再出发行包:
```bash
bash packaging/build-release.sh            # Git Bash 里执行(自带全量测试门禁)
```
或直接双击根目录的 `打包发行包.bat`。

其他命令行参数:`--no-ui`(无显示器服务器)、`--port=8080`、`--setup`(首次运行提示语)。

### 网页端使用
浏览器打开 `http://本机IP:端口`,账号 `admin`,密码为向导中设置的密码。
局域网其他电脑(含 Win7 + Chrome)直接访问同样地址,无需装任何客户端。

## 打包说明(packaging/)

- `build-release.sh`:一键打包脚本 → `packaging/dist/`(四个平台包 + SHA256SUMS);每次构建独立目录,缺运行环境的平台明确跳过
- Windows 包自动使用 `.tools/` 里的 Zulu JRE8;Linux 包的 JRE 已就位
- 在 Windows 上打 Linux 包时,脚本自动处理两处平台差异:JRE 内符号链接转实际文件复制、借 `.exe` 后缀恢复 Linux 可执行权限位
- **建议拿到真实麒麟 arm64 机器上做一次启动验证**

## 安全提示
- 新数据库首次运行必须在本机向导设置密码;`--no-ui` 使用环境变量 `APP_BOOTSTRAP_PASSWORD`(可选 `APP_BOOTSTRAP_USERNAME`)。没有密码时拒绝启动,不创建固定默认密码;初始化环境变量不会重置已有账号。启动成功后应清除本次进程的初始化环境变量,勿把密码写进命令行或仓库
- 密码 PBKDF2 加密存储,连续输错有锁定保护(5 次锁 10 分钟)
- 服务端令牌有效期默认 24 小时,可改 `application.yml` 中 `app.auth.token-expire-hours`
- 默认照片为 `data/photos/`、数据库为 `data/personnel.db`。在线备份使用系统备份入口;复制整目录迁移必须先完全停止服务,并同时保留全部数据、附件和配置,不能在写入期间只拷贝 `.db` 文件
- 默认 HTTP 不加密传输密码、令牌或业务数据。正式局域网部署应使用可信 HTTPS;可直接加载 `packaging/templates/tls.example.yml` 配置原生 TLS,或使用受控反向代理并阻止后台 HTTP 被绕过。不会自动修改防火墙或生成不可信证书
- 动态 SQL 拼接处均有表白名单/参数化防护,并在类头标注 `[受白名单保护]`
