# 数智军营人员管理系统

面向 **Windows 7+ / Linux(x86 与 arm64 麒麟)** 的内网离线人员管理系统。
**免安装、双击即用、浏览器访问**,数据全部保存在本机。

## 技术架构

```
┌──────────────────────┐   HTTP/JSON(Token)   ┌───────────────────────────┐
│  浏览器(任意电脑)    │ ────────────────────▶ │  单文件服务端(内嵌网页端) │
│  Win7/10/麒麟 自带    │                       │  Spring Boot + SQLite     │
│  浏览器即可,零安装    │                       │  双击运行:向导→托盘→浏览器│
└──────────────────────┘                       └───────────────────────────┘
                                               数据:data/personnel.db + photos/
```

| 组件 | 技术 | 说明 |
|---|---|---|
| 服务端 | Spring Boot 2.7 + SQLite(JDK8,Win7/麒麟兼容) | 单 jar 51MB,含启动向导/托盘/网页端 |
| 网页端 | 原生 HTML/JS/CSS,**零第三方依赖** | 离线内网可用,不做 npm 构建 |

> 旧版 Swing 客户端与 systemd 部署脚本已在清理时移除,如需找回见 git 历史(存档提交 `539f748`)。

## 功能

- 双击运行:每次启动先弹设置页(确认/修改端口、管理员账号;密码留空不改;忘记密码随时在此重置)→ 浏览器自动打开 → 托盘常驻
- 端口冲突处理:显示占用进程名,从空闲端口列表一键改用,选定端口持久化
- 管理员密码:首次向导设置;托盘菜单"修改管理员密码"随时重置,不怕遗忘
- 人员管理:档案(30+ 字段)、照片、单位、状态;Excel 导入导出;组合检索分页
- 装备 / 物资(库存预警)/ 车辆 / 休假 / 体能考核 五大业务模块
- 单位树管理、数据字典(军衔/状态/类别等下拉项可自定义)
- 统计报表:总人数、单位人数、性别/状态分布

## 快速开始

### 方式一:发行包(推荐给最终用户)
到 `packaging/dist/<本次构建编号>/`(由 `bash packaging/build-release.sh` 生成)取对应包。每次构建使用独立目录并生成 SHA256SUMS，缺少运行环境的平台会明确跳过，旧目录不会混入本次发行：
- `数智军营-win64.zip`:Windows 7/10/11(64位)→ 解压 → 双击 `启动系统.bat`
- `数智军营-linux-x64.tar.gz`:Ubuntu/CentOS/统信等 x86 → 解压 → `./start.sh`
- `数智军营-linux-arm64.tar.gz`:麒麟/鲲鹏/飞腾 arm64 → 解压 → `./start.sh`
- `数智军营-linux.tar.gz`:轻量通用包(不内置 JRE,要求系统已装 Java8)
- 详见包内《使用说明.txt / README.txt》

### 方式二:源码开发与测试(仓库 `.tools/` 内自带 JDK8 + Maven)
**日常开发直接双击根目录的 `开发运行.bat`**:自动编译最新代码 → 以开发模式在本项目目录启动(数据用项目 `data/`),**不需要打包解压**。

开发模式的热更新规则:
- **改前端**(HTML/CSS/JS):保存后浏览器按 F5 立即生效,**不用重启**
- **改后端**(Java):重新双击 `开发运行.bat`(约 20 秒)

测试满意后再出发行包,二选一:
```bash
bash packaging/build-release.sh            # Git Bash 里执行
```
或直接双击根目录的 `打包发行包.bat`。

其他命令行参数:`--no-ui`(无显示器服务器)、`--port=8080`、`--setup`(首次运行提示语)。

### 网页端使用
浏览器打开 `http://本机IP:端口`,账号 `admin`,密码为向导中设置的密码。
局域网其他电脑(含 Win7 + Chrome)直接访问同样地址,无需装任何客户端。

Excel 导入日期列的填写方式及注意事项见 [Excel 导入日期格式](docs/Excel导入日期格式.md)。
单位累计层级图、所在点位下钻、人员全路径与军人证件号、新模板及前端回归说明见 [单位层级与人员字段](docs/单位层级与人员字段.md)。
编制+实际在岗双单位口径、在岗情况筛选、实际在岗分布图与点名册按实际单位排列见 [实际在岗与编制](docs/实际在岗与编制.md)。
双争年度四季度统计、六字段评比记录与专用 Excel 导入导出见 [双争评比](docs/双争评比.md)。
体能考核宽行导入（一人一行、项目为列、覆盖更新）与汇总视图见 [体能考核宽行导入](docs/体能考核宽行导入.md)。

## 打包说明(packaging/)

```
build-release.sh              一键打包脚本 → packaging/dist/(四个平台包)
templates/win/                Windows 启动脚本与使用说明模板
templates/linux/              Linux 启动脚本、桌面图标生成、说明模板
jres/linux-x64|linux-arm64/   已内置的 Temurin JRE8(8u504,清华镜像下载;原始包备份于 .tools/)
```

> 打包备注:Windows 包自动使用 `.tools/` 里的 Zulu JRE8;Linux 包的 JRE 已就位。
> 在 Windows 上打 Linux 包时,脚本会自动处理两处平台差异:JRE 内的符号链接转为
> 实际文件复制、借 `.exe` 后缀恢复 Linux 可执行权限位(归档时自动去掉后缀)。
> **建议拿到真实麒麟 arm64 机器上做一次启动验证**。

## 安全提示
- 新数据库首次运行必须在本机向导设置密码；`--no-ui` 使用环境变量 `APP_BOOTSTRAP_PASSWORD`（可选 `APP_BOOTSTRAP_USERNAME`）。没有密码时拒绝启动，不创建固定默认密码；初始化环境变量不会重置已有账号。启动成功后应清除本次进程的初始化环境变量，勿把密码写进命令行或仓库。
- 密码 PBKDF2 加密存储,连续输错有锁定保护
- 服务端令牌有效期默认 24 小时,可改 `application.yml` 中 `app.auth.token-expire-hours`
- 默认照片为 `data/photos/`、数据库为 `data/personnel.db`。在线备份使用系统备份入口；复制整目录迁移必须先完全停止服务，并同时保留全部数据、附件和配置，不能在写入期间只拷贝 `.db` 文件。
- 默认 HTTP 不加密传输密码、令牌或业务数据。正式局域网部署应使用可信 HTTPS；可直接加载 `packaging/templates/tls.example.yml` 配置原生 TLS，或使用受控反向代理并阻止后台 HTTP 被绕过。不会自动修改防火墙或生成不可信证书。详见 [部署安全与恢复说明](docs/部署安全与恢复说明.md)。
