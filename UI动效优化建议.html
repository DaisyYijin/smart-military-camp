UI 动效优化建议

基准：scaffold-master（Vue 3 + GSAP 3 通用后台脚手架） 对象：personnel-server/static（原生 ES5 · 零依赖） 2026-11-03
语境差异先说清：scaffold-master 是在线开发的新基座（Vite 6 / npm / GSAP / CDN 可用）；你的项目是离线内网交付系统——零第三方依赖、免构建、Win7/麒麟自带浏览器可用，这是 README 里的架构决策。因此本报告所有建议都在零依赖约束内用原生 CSS/JS 实现，照搬的是 scaffold 的「思想与体系」，不是它的库。

优化点（按优先级）

① 统一动效基础设施

P1 · 基础设施 改动小 · 收益全局

scaffold 的做法

motion.ts

  • EASE 表 5 条曲线（reveal/glide/exit/swap/settle）冻结常量
  • DUR 表 10 档时长（press 0.14s → pageIn 0.62s）
  • 「能量语态」审查：说不出蓄/放/导/结/停摆的动效就是装饰，不做

你的落地路径（原生）

/* app.css */
:root {
  --ease-glide: cubic-bezier(.4,0,.2,1);
  --dur-panel: .3s;  --dur-press: .14s;
  --dur-fade: .3s;   --dur-toast: 2.4s;
}
/* app.js 顶部 */
var MOTION = { panel: 300, toast: 2400, fade: 300,
  glide: 'cubic-bezier(.4,0,.2,1)' };

slideFrom / toast / filter-panel 全部改读这一处表；时长曲线从此只有一个住址。

② 减动效无障碍：全局覆盖

P1 · 无障碍 一行媒体查询的事

scaffold 的做法

  • 7 处 @media (prefers-reduced-motion: reduce) 分布在全部样式层
  • 运行时 prefersReducedMotion()：Canvas 动画直接画终态
  • visibilitychange：切后台时把进行中的补间走完，回来不会停在半路

你的落地路径（原生）

/* app.css 末尾：一处顶过去所有零散处理 */
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: .01ms !important;
    transition-duration: .01ms !important;
  }
}
/* app.js：slideFrom() 入口加一行 */
var rm = matchMedia('(prefers-reduced-motion: reduce)');
if (rm.matches) { el.style.transition='none';
  el.style.transform=''; return; }

军队场景里内网机器开「减少动画」系统设置的不在少数，这是真实用户需求不是点缀。

③ 设计令牌化

P2 · 为暗色主题铺路

scaffold 的做法

  • 四档字色（--ink / muted / soft / faint）撑起信息层级
  • 五档圆角、三档阴影、三档行高密度，全部令牌
  • 深浅两套主题只切令牌，布局与语义不动

你的落地路径（原生）

当前 5 个变量 → 先把出现 ≥ 3 次的颜色 / 圆角 / 阴影收进 :root（如 rgba(23,43,77,.14) 这类阴影色出现了多份）。app.css 用注释分出「令牌 / 基础 / 组件 / 页面」四段即可，不必拆文件。做完这步，暗色模式就是再写一组变量值的事。

④ 浮层过渡一致性

P2 · 手感统一

scaffold 的做法

  • 浮层统一 overlayIn 0.42s / overlayOut 0.2s（入场慢、退场快）
  • 11 处 Vue Transition 共用同一套曲线

你的落地路径（原生）

现状：calIn 动画只服务日历，弹窗（openModal）、下拉、toast 各自为政。把 calIn 推广为通用 pop-in（scale 0.96→1 + fade），openModal / confirmBox / 下拉菜单统一挂它；退场统一快一档（约 0.2s）。改一处 keyframes + 两个 class 名。

⑤ 数据呈现动效 ＋ ⑥ 按压手感

P3 · 锦上添花

⑤ 数据动效

  • 统计数字入场滚动（Odometer 思想，原生 rAF 十几行）
  • 仪表盘卡片 animation-delay 递增级联入场（纯 CSS）
  • rowflash 你已经有了——同类思想可扩展到统计页

⑥ 按压反馈

  • scaffold 用事件委托：命中选择器的控件自动获得同一按压手感
  • 原生版：document 上监听 pointerdown/up，给目标加 .pressing 类（scale .97 + 0.14s）
  • 一处代码，全部按钮/选项卡/行操作统一手感

明确不照搬的部分

scaffold 的东西为什么不适配你的项目
GSAP 3 / Flip 插件CDN 在内网不可达；打包进仓库则破坏「零第三方依赖」决策。CSS transition + rAF 能覆盖你需要的全部动效，scaffold 自己也把重活放在 Canvas 手绘而非 GSAP 特性上
Vue 3 / Vite 6 / TS 构建链免构建是交付特性（改 HTML/JS 按 F5 即生效）；crudView + yearMatrixView 工厂已经在原生范式里证明配置化可行
Canvas 图谱舞台（神经网络 / 导航星系 / 溯源珍珠球）内网人员管理的业务密度撑不起这种视觉投入；其「性能红线」（DPR≤2 / 离屏暂停 / 每帧 try/catch）值得抄进文档，等你真要加 Canvas 时用
