# 物品借还

## 使用范围

物品借还是独立的借用、归还登记台账。一条记录登记一种物品的一次借用，不会自动扣减物资库存，也不会修改装备状态。首版仅支持整笔归还，不支持分次或部分归还。

## 新增借用登记

进入“物品借还”，点击“新增借用登记”。填写物品名称、数量、物品单位、借用人姓名、登记单位和借出日期；可补充规格型号、借用人单位、借用人身份证号码、借用人联系方式、用途/备注。

- 借用人姓名、身份证号码、联系方式、借用人单位均为自定义文本，不从人员档案中选择。借用人姓名必填，其余三项选填；身份证号码和联系方式按文本保存。列表和表单中的借用人信息按“借用人单位、借用人、借用人身份证号、借用人联系方式”排列。
- “登记单位”为必填自由文本，最多200字，可填写任意外单位名称，不要求该单位已在系统单位中建立，也不会按名称自动创建或匹配系统单位。
- “经手人”为选填项，新增、编辑均可通过人员下拉或“选择”按钮选择系统人员，也可选择“(不指定)”清空。新增、编辑表单中的“经手人身份证号”为只读输入框，选定经手人后自动填入其身份证号，清空经手人时同步清空；列表和详情显示服务端保存的经手人姓名和身份证号快照。选择经手人不会改动借用人姓名、证件、电话或单位等独立文本，也不会恢复旧的借用人人员关联。
- 编辑时，原经手人即使已改名、已更换证件、已删除或不在当前可见人员范围内，仍会在本表单中回显已有姓名快照；不改选时保留原人员ID、姓名和身份证号快照，可清空或改选其他可见人员，改选其他人员时显示其当前姓名。历史快照选项仅限当前表单，不会加入全局人员列表或其他表单。同一人员ID的其他记录快照不会相互覆盖。
- 提交字段 `handlerId` 为可选人员ID，清空时传 `0`；`handlerName` 和 `handlerIdCard` 为服务端只读快照，客户端不提交，服务端始终按所选人员的当前档案生成，不接受客户端伪造。
- 新增和编辑表单不选择管理单位。记录归属由服务端根据当前账号确定，客户端不提交 `ownerUserId` 或单位权限字段。
- 数量必须大于零，最多两位小数，最大为 999999999.99。
- 借出日期默认当天，可以修改。列表、详情和借用登记表单仅保留借出日期，不显示预计归还日期或实际归还日期；新增、编辑及归还登记均不提交这两个归还日期字段。
- 未归还记录可以编辑借用信息。已归还记录保留供查看，不再通过普通编辑修改。

## 登记归还

找到尚未归还的记录，点击物品名称旁的“快捷归还”按钮，即可打开整笔归还表单，无需横向滚动到最右侧。右侧“登记归还”和详情中的“登记归还”也保留。填写归还情况及选填的归还备注，再点击“确认归还”才会保存；打开快捷入口不会直接归还。归还登记不填写实际归还日期。

保存后整笔登记为已归还。归还不会删除借用记录，可继续查看借用及归还情况；重复提交不会覆盖已登记的归还信息。

## 查询与状态

支持按物品名称、借用人、手填登记单位、状态查询。状态下拉仅提供“全部”“借用中”“已归还”，其中“全部”表示不限制状态；不再提供“已逾期”筛选或状态。

| 状态 | 判断规则 |
| --- | --- |
| 借用中 | 归还登记尚未完成。 |
| 已归还 | 已完成归还登记。 |

状态由系统根据归还操作自动维护，不需要手工修改；不会根据当前日期、借出日期或旧归还日期推算逾期状态。

## 权限、备份与数据保留

- 新建记录的权限归属由服务端记录创建账号。创建者及其账号子树可访问记录；全局管理员可按管理权限访问。登记单位、借用人姓名、借用人单位等自由文本不用于授权。
- 历史旧记录若没有可用的创建账号归属，仅全局管理员可见；不会因为登记单位名称与当前单位匹配而开放给子账号。
- 单位信息与借还记录的权限归属相互独立。删除单位、调整单位树或恢复单位数据不会删除、转移或改变借还记录的归属；借还记录也不阻止单位删除。
- 备份时可单独选择“物品借还”模块，自动备份配置也独立包含该模块。只备份或恢复单位、人员等其他数据，不会改动借还台账；需要迁移借还记录时应在备份中显式包含该模块。
- 旧备份未包含物品借还时，恢复不会清空本地借还记录。删除或调动人员也不会删除或修改借还台账。日常归还应使用“登记归还”，不要删除人员或借还记录来表示已归还。
- 升级时，旧记录从原关联人员的一次性迁移中取得姓名、身份证、电话和单位，随后成为独立保存的文本。迁移使用当时的档案资料，不代表借出时的历史资料；后续手填修改不会被人员档案覆盖。找不到原人员或有效单位的旧记录仍保留，仅全局管理员可见。旧备份和旧人员删除快照中的借还记录恢复时也会做同类转换。
- 新增手填登记单位字段时，既有记录首次按原管理单位名称补入文字，不修改归还资料及时间戳；以后启动不会覆盖手填。旧备份缺少该字段时按恢复快照可用资料补入；已包含该字段（包括空文本）的快照保持原值。
- 升级会将旧实际归还日期非空的记录迁移为“已归还”。数据库、旧备份和撤回快照中的预计/实际归还日期列及历史值会保留兼容，但不再显示、写入或用于状态判断。
- 本模块首版不提供 Excel 导入、导出、审批、库存联动或多物品单据。
