# 驾驶证筛选、仪表盘与花名册

## 人员管理筛选

右侧筛选面板新增驾驶证、驾驶证类型、驾驶证状态。类型与状态按同一条驾驶证记录联合匹配，不会把一张证的类型与另一张证的状态拼成命中。

- 驾驶证：全部／有驾驶证／无驾驶证。
- 类型：军本、地方本，以及字典中的自定义类型。
- 状态：有效、过期、吊销，以及字典中的自定义状态。

“有驾驶证”表示已登记至少一条驾驶证子档案，包括过期、吊销及状态未填写的历史记录，并不代表当前具有有效驾驶资格。状态与日期均以档案填写值为准，不自动改写。

筛选条件按逻辑交集执行；选择“无驾驶证”时若仍限定某种证件类型或状态，将不会命中人员。点名册与花名册会沿用当前驾驶证筛选条件。

## 仪表盘

新增“驾驶证持有情况”图，按权限范围内的人员去重统计“有驾驶证／无驾驶证”。一人多证或重复登记仍只计一人，两项之和等于当前可见人员总数，孤立证件记录不计入。

点击图表相应分组进入人员管理，自动带上对应的有／无驾驶证筛选，使用人员页正常分页，不再调用旧的固定条数明细弹窗。

新默认布局含该图。原保存布局若精确等于旧默认布局，首次加载时补入一次；自定义尺寸、顺序或子集不强制补图。迁移标记随原账号布局保存，手动删除该卡片后不会反复恢复。也可通过“添加图表 → 人员管理 → 驾驶证持有情况”自行添加。

## 花名册可选字段

花名册下载的字段按钮由服务端动态提供，新增以下可选项；默认字段和默认不预选的行为不变。

| 显示名称 | 字段 key |
|---|---|
| 驾驶证（汇总） | driverLicense |
| 有无驾驶证 | hasDriverLicense |
| 驾驶证类型 | driverLicenseType |
| 驾驶证号 | driverLicenseNo |
| 准驾车型 | driverVehicleClass |
| 驾驶证初领日期 | driverIssueDate |
| 驾驶证有效期至 | driverExpiryDate |
| 驾驶证状态 | driverLicenseStatus |
| 驾驶证年审日期 | driverReviewDate |
| 驾驶证发证机关 | driverIssuingAuth |

建议勾选“姓名＋驾驶证”，或者按需要选择证号、车型、日期等独立明细列。

一人仍只占一行。多证按登记ID稳定排序，在同一单元格内分行；各列使用相同的 `[1]`、`[2]` 顺序，已登记证件的缺失值用 `—` 占位，避免证号、类型、日期错位。无证人员“有无”为“无”、汇总为“无”，明细列为空。证号保持文本，前导零不丢失。

日期沿用花名册中文日期格式；无法解析的历史日期保留原文。驾驶证明细仅在选中相关字段时按最终人员ID批量加载，并再次限定人员权限。人员身份证为空的历史档案仍可按人员ID导出其驾驶证。

列宽和行高会为证件分行及折行预留空间；Excel单行最高409磅，极多证件可能需要通过公式栏查看完整内容，或使用人员完整Excel中的“驾驶证”独立Sheet逐证查看。单元格超过32767字符时明确报错，不静默截断。实际纸面效果仍取决于Excel/WPS及字体设置。

## 与点名册驾驶员标志的区别

本次不改变旧标志规则：点名册的驾驶员标志仍依据“至少一条非吊销记录”，包含过期或空状态记录。“有无驾驶证”是登记记录口径，两者不是实际驾驶资格认证。

本功能不向外部网站查询或验证证照，不修改人员档案或驾驶证原始数据。
