# 账号与单位权限

## 使用方法

1. 使用现有管理员账号登录，打开左侧“账号管理”。原有管理员账号及密码不变。
2. 点击“新增子账号”，填写账号、显示名称、初始密码，并勾选该账号负责的单位。
3. 一个账号可分配多个单位。每个勾选单位的所有下级单位都属于管理范围，后续新增的下级单位也自动纳入。
4. 分别创建 B、C 并选择各自的单位，即可让两个账号独立管理各自的数据。若给两者分配重叠的单位，则两者都能管理重叠范围。

未勾选任何单位表示没有单位业务数据权限，不表示管理全部单位。

## 上下级账号

- 每个账号只管理自己直接创建的子账号，不能编辑自己、上级或同级账号。
- 子账号也可以建立自己的子账号，但不能授予超出本人及所有上级有效范围的单位。
- 编辑子账号可以调整显示名称、单位范围、启用状态及密码；用户名创建后不能修改。
- 编辑时密码留空表示不修改密码，非空密码至少 6 位。
- 不提供删除账号，停用后保留账号关系。停用上级账号会同时阻止其所有下级账号登录。
- 停用、重设密码或调整单位授权后，该账号及其下级的现有登录会话失效，需要重新登录。收回上级授权后，下级的实际权限也会相应缩小。

## 业务数据范围

权限在服务端校验，并非只隐藏菜单：

- 人员按所属单位控制。
- 枪支、大型装备、小型装备及物资按保管人所属单位控制。
- 车辆按驾驶员所属单位控制。
- 手机、休假登记、休假计划、体能考核、军事考核及人员子记录按关联人员所属单位控制。
- 列表、总数、详情、照片、人员选择器、统计、普通增删改、Excel 导入导出均受同一范围限制。
- 未设置保管人、驾驶员，或者关联人员没有有效单位的资产，仅全局管理员可管理。应由管理员先补齐归属。
- 人员调动会同步改变其关联记录及名下资产的可见范围。

子账号可以在授权单位下新建子单位、修改单位信息或删除未使用的空单位，但不能调整单位层级；已直接分配给账号的单位必须先取消相关授权后才能删除。

## 全局管理功能

备份恢复、系统设置、全局操作日志、上报数据包，以及人员删除撤回仅供全局管理员使用。数据字典、体能评分标准、军事考核方案等共享配置由管理员维护，子账号业务表单仍可读取和使用这些选项。

Excel 继续使用各模块原有导入规则。若某行通过身份证、装备识别码或车架号等业务键命中其他单位的数据，该行会被拒绝，不会抢占或覆盖范围外记录；其他合法行可继续导入。

本机启动向导和托盘的密码恢复仅作用于配置中的根管理员，不用于重置子账号。子账号密码应由其直属上级在账号管理中重设。
