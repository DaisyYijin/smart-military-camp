# 单位层级与人员字段

## 仪表盘

- 新仪表盘或“恢复默认”布局直接显示“所在点位”。已有自定义持久布局不自动强制补图，尊重原有排序及删除选择；可在“添加图表 → 人员管理”中添加“所在点位”。数据来自人员的 `locationPoint`（数据库 `location_point`），选项沿用 `personnel_location` 字典。点击真实点位跳到人员列表并带上该点位筛选；空值仍显示“未填写”，不伪造空值筛选，也不下钻。
- “各单位人数（含下级）”固定为单位层级条形图：按接口稳定树前序展示全部可见单位，不按人数重排、不截取前15个。路径可换行并有完整悬浮提示；层级以颜色和缩进区分，真实根为第1级（接口 `depth=0`），同名单位同时显示ID。
- 单位条形数值为当前权限范围内“直属 + 全部下级”；直属人数另列。上、下级有重复包含关系，不能把各行相加，也不能当作环形图/玫瑰图的可加总分组。总人数卡仍使用后端总人数，不从单位图求和。
- 旧版保存的单位条形/环形/玫瑰/矩形树图自动迁移为专用层级图，保留该卡片尺寸、所在顺序及用户的其他图表布局。重复存在的旧单位卡片不会吞掉其他配置。
- 点击单位按ID跳到 `#personnel?departmentId=<ID>&includeDescendants=true`，仅查询该单位及其可见子树，不按名称反查。筛选区明确提示“包含全部可见下级”；手动更换单位、清空单位或重置筛选后恢复仅直属，并清除子树标志。点名册和花名册下载沿用当前真实筛选，不携带上次下载的标志或排序选项。
- ID为0的“未分配”单独灰色显示，其人数保留，但不下钻；它不是一个新增的可选单位。

## 人员单位全路径

人员JSON的 `departmentPath` 为只读计算值，例如“某营 / 一连 / 二排 / 三班”，`departmentName` 继续保留叶子单位名。人员列表、详情、选人弹窗、选中后的摘要及相关档案优先展示完整路径；旧接口缺少路径时回退叶子名。路径可读换行并有悬浮提示，不截成单层。

新增/编辑仍提交 `departmentId`，不能通过可读祖先名称扩大单位选择或权限树。单位下拉只构建后端已授权的树节点；同名单位由ID值区分。

## 军人证件号

“军人证件号”（`militaryIdNo`）位于人员新增/编辑“基本信息”标签的身份证号附近：

- 独立必填文本，有红星、原生必填属性及通用空白校验；不套身份证校验，不预设格式，不要求唯一。
- 不从身份证号自动补入；新建和编辑均提交本字段。历史空记录展示“未填写”，读取不会改写历史值，编辑保存前须补齐。
- 人员列表、详情以及后端提供的可配置花名册字段清单均接入此字段。
- Excel导入请重新下载最新多Sheet模板，补齐必填“军人证件号”列再导入；旧模板缺列时应使用新模板修正，不能拿身份证列代替。原有多种日期填写规则不变，见 [Excel导入日期格式](Excel导入日期格式.md)。历史数据原样保留，旧备份仍可按原备份恢复流程恢复。

## 点名册下载说明

点名册Excel使用横向单位块：同一上级的子单位从左到右排列。每个单位先显示合并标题，本级每个人各占下一行，姓名行的合并范围与该单位标题一致；本级人员列完之后，才在下方显示子单位及班内人员。没有本级人员时直接接子单位，不另加“直属人员”标签或姓名专列。不限定营/连/排/班层数，所有单元格不填充底色。不在位原因块保持独立。仍为横向A4，身份标志默认全不选，可选9种排序字段、最多5级条件；排序只在单位直属姓名和不在位原因块内部进行，不改变单位树顺序。具体打印规则见 [点名册打印](点名册打印.md)。

## 前端回归

在仓库根目录运行：

```sh
node --test "personnel-server/src/test/frontend/*.test.cjs"
node --check personnel-server/src/main/resources/static/app.js
node --check personnel-server/src/main/resources/static/ext-features.js
```

测试仅使用轻量DOM和隔离请求，不读取正式业务数据库。真实服务浏览器验收仍需核对权限账号、Excel生成结果和长路径在实际屏幕下的排版。
