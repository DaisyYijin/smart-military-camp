# 体能考核宽行导入（一人一行）

## 模板与格式

下载模板（体能考核 → 下载模板）为宽行格式：**一人一行，每个考核项目占一列**。

- 前三列固定为姓名、身份证号码、考核日期。
- 其后各列列头为数据字典「体能项目」的启用项，按字典排序生成；停用项目不出现，自定义项目自动加入。
- 项目单元格填写该项目成绩；**留空＝未参加该项目**，不生成记录也不报错。
- 成绩格式与旧版一致：时间类可填 `12'30"`、`12:30`、`12分30秒`；次数类填数字；BMI 项目填体重千克数。考核日期支持 `2026-01-31`、`2026/1/31`、`20260131`、`2026年1月31日` 及 Excel 日期单元格。
- 身份证号码列已设为文本格式，避免精度丢失。

## 覆盖更新（不再是纯追加）

同一人员 + 同一考核项目 + 同一考核日期重复导入（含同一文件内重复行）时**覆盖更新**：更新成绩并按体能标准重新计算分数与评定等级。导入结果分别显示新增、更新、失败数量，失败行标注 Excel 行号与项目名，整行事务回滚，不影响其他行。

旧版「一项一行」格式（含「考核项目」「成绩」列）**仍可直接导入**，系统按表头自动识别，同样按覆盖更新处理，无需单独模板。

某项目补测日期不同时，另起一行只填该项目的成绩即可。

## 汇总视图与导出

- 体能考核页新增 **「汇总视图」** 切换：一人一行、各项目为列，单元格显示「成绩（分数/评定）」，无该项目显示「—」；只读，编辑请切回记录视图。筛选与分页与记录视图同口径但相互独立。
- **导出**默认为宽行：勾选记录导出所选，或按当前筛选导出全部；单元格同样为「成绩（分数/评定）」。

## 口径说明

- 分数与评定由系统按体能标准（项目×年龄段）与评定标准权威计算，导入只是写入成绩。
- 权限沿用体能考核数据范围，子账号只能导入、汇总、导出权限内人员。
- 本功能不改变单条记录的存储结构，历史数据无需迁移。
