# 点名册 Excel 下载与打印选项

## 入口与打印方式

在人员管理中先设置当前筛选条件，再点击“点名册下载”。弹窗用于设置本次 Excel 导出的身份标志和人员排序，不是浏览器打印窗口；点击“下载 Excel”仍调用 `/api/personnel/rollcall/excel`，保留原有生成、下载进度。

下载后用 Excel 或 WPS 打开工作簿，通过软件的“打印预览/打印”操作打印。本次未新增浏览器打印、PDF 导出或页面打印入口。

现有后端生成的工作簿采用横向 A4、宽一页且高一页（整表缩放到一页）、水平居中，并设置打印区域。人数较多时整页缩放可能导致字小，请在 Excel/WPS 中预览，按需要调整缩放或分页。休假人员可显示归队时间；身份标志与排序选项不会改变工作簿版式、字体或打印设置。

## 多级单位版式

在位人员按单位 **ID** 建立横向树形表头，支持营、连、排、班及更深层级：

1. 同一上级的子单位按 `sort`、`id` 从左到右排列。例如一排右侧是二排，一排所属一班右侧是二班。
2. 单位标题横向合并覆盖所有下级列；本级每名在位人员各占下一行，姓名行与该单位标题合并相同范围。长单位名称或姓名按合并宽度预留换行行高。
3. **先显示单位标题，再逐行显示本级人员，最后才显示子单位标题和班内人员**，不显示“直属人员”标签，也不设置额外的本级人员专列。例如三排标题合并三列时，顾宇轩姓名行也合并这三列，之后的各班再从左到右排开。没有本级人员时，下一行直接显示子单位。
4. 兄弟单位本级人数不同时，其下属班级可以在不同的行开始，不留空行强制对齐。不在位区域排在全部在位单位块结束之后。所有单元格不填充底色，保留黑色文字和边框。超过 Excel 的 16384 列限制时提示缩小筛选范围。

同名但 ID 不同的单位分别显示，不跨分支合并。只显示本次筛选命中的在位人员及其必要祖先标题，无人员命中的其他分支不展示；必要祖先没有本级命中人员时，仍保留覆盖下级的合并表头，不生成空的本级人员列。标题中的“在位 N 人”是本次筛选、当前权限内该单位及下级的可见在位总量，不引用全库单位人数，也不因展示祖先而纳入权限范围外的人员。未分配、零单位 ID、缺失单位及孤儿单位人员均保留，其中缺失单位按 ID 独立成列。

不在位人员仍按原因分块：左侧原因列纵向合并，右侧姓名横向排列，姓名下方可保留归队时间。底部仍显示本次筛选的应到、在位、不在位人数。仍保持横向 A4、宽一页且高一页、现有页边距和打印区域，不自动新增分页策略。

## 身份标志

- 党员、团员、驾驶员均为原生按钮，复用 `field-chip` 样式，不再使用复选框。
- 每次打开均默认全不选；点击切换选中状态，蓝色表示选中，`aria-pressed` 与状态同步。原生按钮支持 Tab 聚焦、Enter/空格激活。
- “全选标志”“全不选标志”只作用于三个身份标志，不增删排序条件，不更改字段、方向或优先级。
- 允许全部不选并下载，此时不发送 `marks`。选中时按 `party,league,driver` 的固定顺序发送已选项。
- 党员、团员标志位于姓名前；驾驶员标志位于姓名后（驾驶证吊销除外）。党员同时为驾驶员时可以同时显示。

## 人员排序设置

初始只有“第一排序条件”，字段为空，表示不排序。可以添加第二至第五条件，每行均有字段、方向、移除、上移和下移按钮；也可删除所有行。上下移动改变条件优先级，不丢失原字段及方向。移动端各行和标志区可换行。

第一条件相同时再比较下一条件。空行忽略，没有有效条件则不发送 `sort`、保留原来人员顺序；没有排序也允许下载。重复字段或无效字段/方向会在弹窗内提示，阻止下载且不关闭弹窗，可直接修正。

前端通过点名册请求的 `q.sort` 发送协议，例如：

```text
sort=serviceYears:desc,rank:desc,name:asc
```

实际 URL 中参数值经过编码。选项仅在本次点名册弹窗中生效，不保存到人员列表筛选、不混入花名册或其他导出。

| 字段 | 协议键 | 默认方向 | 方向含义 |
| --- | --- | --- | --- |
| 军龄 | serviceYears | desc | 高到低 / 低到高 |
| 军衔 | rank | desc | 高到低 / 低到高 |
| 年龄 | age | desc | 大到小 / 小到大 |
| 姓名 | name | asc | 中文正序 / 中文倒序 |
| 入伍/入职时间 | entryDate | asc | 早到晚 / 晚到早 |
| 任职时间 | postDate | asc | 早到晚 / 晚到早 |
| 人员类别 | category | asc | 中文正序 / 中文倒序 |
| 学历 | education | desc | 高到低 / 低到高 |
| 职务/岗位 | post | asc | 中文正序 / 中文倒序 |

切换字段会恢复该字段的合理默认方向，之后可以自行修改方向。

### 后端排序口径与验证边界

- **军龄**：优先使用有效且不晚于今天的相当入伍日期 `equivEntryDate`；为空、非法或未来日期时，兜底有效且不晚于今天的入伍日期 `entryDate`。按精确日期比较，不以取整军龄年数比较；同日期再比较下一条件。
- **年龄**：按有效出生日期比较，未来出生日期无效。军龄没有可用日期、年龄日期无效，以及其他空值/无效值，在升降序下均放最后。
- **日期解析**：标准格式为严格有效的 `yyyy-MM-dd`；后端兼容历史数据 `yyyy-MM`、`yyyy`、`yyyyMMdd`，缺日/月取该月/年首日。非法日历日期无效，不把时间戳截成日期，也不接受斜线或点号日期。
- **军衔**：使用明确高低而非字典序号。降序为上将、中将、少将、大校、上校、中校、少校、上尉、中尉、少尉、一级军士长、二级军士长、三级军士长、一级上士/四级军士长（同档）、二级上士/上士（同档）、中士、下士、上等兵、列兵；未知军衔/职级放末尾。同档继续比较下一条件。
- **学历**：后台明确等级为博士 > 硕士 > 本科 > 大专 > 高中/职高/中专（同档） > 初中 > 小学；同档比较下一条件。博士研究生与博士同档，硕士研究生与硕士同档；大学本科与本科同档，专科/大学专科/高职与大专同档；普通高中、职业高中、中等专科归入相应高中阶段。未知学历或含糊的“研究生”放末尾，不猜测为硕士。
- **中文文本**：姓名、类别、职务/岗位按中文文本排序，职务/岗位不是职位高低。
- 排序只改变**各单位直属人员**及**各不在位原因**内部的姓名顺序，不跨单位、跨原因排序，不改变单位层级及 `sort`、`id` 顺序。所有有效条件相同或 `sort` 为空时保留人员查询原序，不追加 ID 等隐式排序键。

排序由后端 `RollCallExcelService` 执行，只作用于本次导出，不修改人员档案或人员列表的默认顺序。工作簿中的姓名顺序和打印设置可由自动化测试验证，实际打印预览与纸面效果仍取决于目标电脑的 Excel/WPS、字体和打印机配置。
