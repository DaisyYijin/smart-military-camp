# 双争评比

## 先选人员，再查看记录

- 菜单和刷新恢复入口沿用 `#double-excellence`。主页面默认是评比记录，初始提示“请先选择人员”，不加载全员记录、不允许空选人导出。年度考评仍为待完善占位。
- 点击“选择人员”，通过现有搜索弹窗每次添加一人，可重复操作，最多 200 人。按人员 ID 去重，同名不同人分别保留；姓名标签悬浮显示身份证和单位路径，可逐个移除或“清空人员”。选择只存在当前页面内存，不持久化姓名、身份证等敏感信息。
- 主记录查询、筛选、分页、刷新和导出始终携带精确 `personnelIds`，不会用姓名模糊匹配代替人员范围。记录复选框只表示选中的评比记录，与人员选择相互独立。
- 清空最后一人立即清空记录、总数、记录勾选并使旧请求失效，不发送无人员范围的查询。旧响应不得把人员列表重新填回。
- 右侧筛选为年份、季度、姓名、身份证号码、单位（含下级）、评定、评比日期开始/结束。筛选开关与其他 CRUD 页采用相同滑入和 310ms 收起逻辑，不重建主页面，保留内容区和筛选区滚动位置；快速点击、导航或退出登录会取消旧动画与关闭回调。

## 独立年度统计弹窗

点击“统计”打开大窗口，不替换主记录页面，也不在弹窗内构造另一套 body 固定筛选面板。

- 有已选人员时默认统计这些人员；未选人时默认统计全部当前权限可见人员。范围按钮为“所选人员”和“全部可见人员”，无所选时禁用前者。标题区域明确显示当前范围及服务端匹配总人数；只有全部可见范围不传 `personnelIds`。
- 弹窗独立维护年份、季度/评定筛选、页码、加载状态和请求序号。提供“上一年 / 本年 / 下一年”、近五年快捷按钮和年份数字框，允许范围统一为 1900..9999，边界按钮禁用。切换立即查询弹窗自身，不改主记录年份、人员选择或页面滚动。
- 四季度矩阵按人员显示好、中、一般；没有记录的季度显示“未评定”，全年无记录人员也在相应人员范围内显示四个未评定。四张季度卡片与匹配总人数使用后端全集结果，不按当前记录页或当前统计页累加。
- 仅选季度、评定全部时仍包含该季度未评人员；仅选评定时任一季度满足即匹配，同时选季度时仅匹配指定季度。“未评定”只在统计筛选使用，不是评比记录或可保存评级。
- 统计按当前可见现有人员，而非历史在册名册。弹窗每次打开重新请求；年份快切、分页、范围切换、关闭及页面失效均有过期响应保护。

## 六字段评比记录

可见业务字段固定为：**年份、季度、姓名、身份证号码、评定、评比日期**。内部记录 ID、人员 ID 是关联标识，不增加业务字段。

- 新建默认当前年份、季度和今天日期；评比日期可以跨评定季度。
- 姓名通过“选择”现有人员带入，或填写身份证完成反查。姓名只读，身份证与隐藏人员 ID 必须匹配；修改证号会立即清除旧关联，未完成查询不能保存，不创建虚假档案。
- 评定仅允许“好 / 中 / 一般”。同一人员、年份、季度已存在时，手工新增提示请编辑，不静默覆盖。
- 新增、编辑、删除成功后只刷新当前人员范围。在表单主动选择了主列表之外的人员，保存成功会在未达 200 人上限时将其加入当前选择，再刷新，不会显示全部人员。

## Excel

右上保留“导入导出”“下载模板”，使用携带登录令牌的专用上传下载进度工具。

- 模板六列依次为年份、季度、姓名、身份证号码、评定、评比日期；使用 `.xlsx`，身份证按文本填写。日期支持系统 Excel 日期解析规则，见 [Excel 导入日期格式](Excel导入日期格式.md)。
- 导入前确认按**身份证号码＋年份＋季度**组合键匹配：不存在则新增，已存在则更新评定和日期。人员必须已建档。
- 专用导入限制为 10MiB、50000 数据行、64 列、16 个工作表；前端预检扩展名和大小，最终由服务端校验。显示新增、更新、失败数量及失败原因；锁定重复提交，失败后可重选同一文件重试。
- 导入成功或部分成功后只刷新当前所选人员，不自动把整个文件中的人员加入主列表。无选择时仍保持空态，提示选择人员查看。
- 导出必须先选择人员。勾选记录时传评比**记录 ID**及当前 `personnelIds`；未勾选时导出当前人员范围与筛选的全部匹配记录，不局限当前页。绝不将人员 ID 当记录 ID，不允许空选人扩大为全量导出。统计弹窗不提供虚假的未评定记录导出。
- 导出最多 50000 条，超出请缩小筛选范围。离开页面或登录状态变化后，过期上传结果不覆盖新页面。

## 接口与前端回归

- `GET /api/double-excellence`：分页记录，主页面必带 `personnelIds`；`GET /{id}`、`POST`、`PUT /{id}`、`DELETE /{id}` 为记录读写。
- `GET /api/double-excellence/stats`：返回 `year / total / list / quarters`；所选范围带 `personnelIds`，全部可见范围不带，最终始终受后端 scope 约束。
- 同一基础路径下 `GET /template`、`POST /import-excel`（表单 `file`）、`GET /export` 为专用 Excel 接口。

前端回归执行真实生产函数，使用轻量 DOM、可控计时器与模拟传输，不访问正式数据：

```bash
node --test personnel-server/src/test/frontend/*.test.cjs
```
