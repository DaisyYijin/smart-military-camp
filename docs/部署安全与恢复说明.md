# 部署安全与恢复说明

## 首次启动与已有部署

新数据库不再生成固定密码的管理员。桌面启动时，在本机向导中设置账号和 6 至 256 位非空密码。建议使用长且唯一的口令。首次初始化完成前，服务不会进入可用状态。

无界面部署先通过受控进程环境设置 `APP_BOOTSTRAP_PASSWORD`，可选 `APP_BOOTSTRAP_USERNAME`（默认账号名 `admin`），再运行：

```text
java -jar personnel-server.jar --no-ui --port=8080
```

没有密码时新数据库拒绝启动。不要通过命令行参数传密码，也不要把密码保存进批处理、YAML、日志或版本库。启动成功后，清理用于启动的环境变量；不要删除或覆盖数据库。已有账号存在时，初始化变量不会改名或重置密码。已有部署遗留的弱密码不会被自动更改，应由用户在本机受控入口或登录后的修改密码功能中处理。

数据库位置由 `spring.datasource.url` 决定；照片与备份由 `app.data-dir` 决定。更改目录前需同时确认两处，程序不会自动搬迁历史数据。

## 局域网 HTTPS

默认 HTTP 只为兼容既有离线/单机部署，不提供传输机密性。不要把 HTTP 后端直接暴露到互联网。局域网中也应使用受信任的内部 CA 证书。

### 原生 TLS

1. 由管理员提供 PKCS12 密钥库。证书的 SAN 应包含客户端实际使用的名称/IP，客户端须信任签发 CA。
2. 复制 `packaging/templates/tls.example.yml` 到运行目录并命名为 `tls.yml`。
3. 通过受控进程环境设置 `APP_TLS_KEYSTORE`（密钥库路径）和 `APP_TLS_KEYSTORE_PASSWORD`。
4. 在原启动命令后添加：

```text
--spring.config.additional-location=file:./tls.yml
```

启动器和托盘根据实际 SSL 配置生成 HTTPS 地址。原生 TLS 使用同一端口，不另外开放 HTTP。若使用 `https://127.0.0.1` 时证书没有该 SAN，请改用证书中的名称，不要关闭证书校验。不要混用 HTTP 与 HTTPS 书签或忽略浏览器证书错误。

### 反向代理

也可由经维护的 Nginx/IIS 等终止 HTTPS。此时必须用监听地址/防火墙/网络隔离限制后台 HTTP 端口，仅允许代理访问，避免客户端绕过 HTTPS。不要盲目信任外部提交的转发头。不同 Win7 浏览器/JRE 和麒麟版本仍须在目标环境验证证书链、TLS 1.2 与时间设置；没有证书或目标环境时不能视为 HTTPS 已验收。

## 备份和恢复

- 自动备份的唯一调度配置位于备份恢复页面，对应 `/api/backup/settings`。不要把主题与显示的旧 `backupKeep` 设置当作定时任务配置。
- 备份恢复页面的“上传备份并恢复”入口在列表为空时也可使用，仅接受非空 `.zip` 备份文件，单个文件上传限额为 100MB（100 × 1024 × 1024 字节）。前端校验不替代服务端校验；应先确认备份来源可信。
- 恢复分两步：先上传保存文件并刷新列表，再在自动打开的确认弹窗中选择模块并点击“开始恢复”。上传成功绝不会自动执行恢复；取消确认不会删除已上传文件，之后仍可从列表点击“恢复”。上传或恢复失败后可重试，请勿重复提交进行中的操作。
- 确认弹窗仅提供备份实际包含且当前系统支持的模块。所选模块的数据在同一个事务中恢复，不是逐模块独立提交；系统配置文件在数据事务完成后另行恢复，失败会保留原配置并显示警告。
- 新备份为各模块记录附件范围，只恢复人员模块不会覆盖车辆、装备、物资的照片。v4 人员备份同时恢复删除撤回记录及其回收站照片；旧备份没有资产照片快照时保留当前资产附件并提示覆盖限制。
- 账号与单位授权必须配套恢复。旧包缺少授权关系时，不应单独覆盖账号产生新旧授权错配；程序会跳过不安全的账号恢复并给出警告。
- v4 人员模块同时包含删除撤回记录及其回收站照片；数据字典/系统数据（`dict`）模块同时包含自动备份设置和启动配置。旧备份缺少这些内容时，恢复会清空本地撤回缓存或保留本地配置，并显示提示。
- 启动配置中的端口等变更在恢复后不会立即切换，下次重启才生效。
- 恢复影响账号/授权或单位树后，已登录会话会失效，必须重新登录。
- 系统在实际恢复前自动创建安全备份；仍建议事先下载备份并异地保留。正式使用前应在隔离副本上演练恢复，核对记录、授权和附件数量。不要把未演练的备份数量等同于可恢复性。
- 全目录复制只可在完全停止服务后进行。SQLite WAL 模式在运行时可能还有 `-wal`、`-shm` 文件，不能运行中单独复制主 `.db` 文件。
- 从其他单位收到的上报文件也应视为不可信输入，确认来源后再预览导入。导入人员时不会接受源端照片磁盘路径。

## 共享终端和个人偏好

登录页面不再保存真实密码，并会清除旧版本的 `savedPass` 键。需要记忆凭据时使用受控的浏览器密码管理策略。退出后不要保留敏感页面，避免其他人使用同一浏览器会话。

仪表盘布局、侧栏状态及默认页面按当前认证账号隔离，不会把旧共享键自动转交给子账号。全站名称、LOGO、主题仍属于全局品牌配置。
