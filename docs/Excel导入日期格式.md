# Excel 导入日期格式

先下载对应业务的系统模板，按原列头填写，并保存为 `.xlsx` 后通过导入窗口上传。不要将 CSV 或旧版 `.xls` 仅修改后缀为 `.xlsx`。

## 日期列怎么填

日期列支持20160901、2016-09-01、2016.09.01、2016/9/1、2016年9月1日及Excel日期单元格，统一识别真实日期，非法日期会报错。

以上示例都表示 `2016-09-01`。Excel 日期单元格是实际保存为日期类型的单元格，不是任意普通数字；无日期样式的普通序列数（如 `45200`）不会猜作日期，`20160901` 则按年月日识别。

- 适用于人员档案及模板内子表的日历日期列，以及枪支、大型/小型装备、车辆、手机设备、体能考核成绩、军事考核、休假登记和休假计划模板中的日期列。
- 必须填写真实存在的日期，例如 `20160230`、`2016-13-01` 均为非法日期；请按导入结果提示修正后重试。
- 本说明不承诺支持时间戳、日/月顺序、仅年份或年月，以及任意数字序列作为日期。

## 日期单元格与公式的边界

- 使用 1900 或 1904 日期系统的工作簿，原生日期单元格均可识别。
- 1900 日期系统下，带日期样式的 `DATE` 公式可识别；返回上述受支持日期文本的公式也可识别。
- 当前 POI 4.1.2 的 `DATE` 求值固定使用 1900 日期系统，因此 1904 日期系统工作簿中的数值日期公式会明确报行级错误，不会静默导入错误日期。请在 Excel 中确认结果后，将公式复制并“选择性粘贴为值”，保留日期格式，以日期值重新导入。

## 非日期列保持原规则

- 物资模板不含日历日期列，不显示日期格式提示。
- 体能标准的分数、年龄段、秒数，以及成绩、数量等非日期字段，仍按各自模板规则填写，不按日期解释。
- 身份证号、装备编号、序列号、IMEI 等普通编号长串，建议在填写前将单元格设为“文本”，避免前导零丢失、科学计数法或长数字精度损失；已经丢失的位数不能靠修改格式恢复。

本说明不改变各模块原有的匹配更新或增量导入规则，也不改变点名册逻辑与排序。
