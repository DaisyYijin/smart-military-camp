# 编制 + 实际在岗（人员双单位口径）

人员档案在“编制单位”之外，可再登记**实际单位**，用于借调、代职、帮带等“人在别的单位干活、编制还在原单位”的场景。两组信息并列展示、互不覆盖。

> 说明：早期版本还包含“实际岗位”“实际在岗开始时间”两个字段，现已从表单、接口与导出中移除；数据库列 `actual_post` / `actual_post_date` 保留不动，历史值不再显示、不再读写。

## 口径（重要）

1. **编制权威**：`单位`（编制单位）是人员的权威归属，权限、数据范围、统计口径全部以编制单位为准，与此前完全一致。实际单位只是补充描述，不参与任何权限判断。
2. **实际可选**：实际单位可不填。**留空（或 0）表示“在编在岗”**，即人就在编制单位正常工作。
3. **权限按编制**：账号的数据范围、单位树可见性、各模块筛选授权均按编制单位计算；实际单位可以选权限树以外的单位（例如借调到友邻单位），不影响本人或他人能看到哪些数据。
4. **点名册默认编制**：点名册、花名册等导出默认仍按**编制单位**分组排列；需要按实际单位点名时，在点名册弹窗中手动开启“按实际单位排列”，且仅对本次下载生效。

## 字段与展示

| 字段 | 键 | 说明 |
| --- | --- | --- |
| 实际单位 | `actualDepartmentId` | 下拉选择单位，可选；留空=在编在岗。人员 JSON 同时返回 `actualDepartmentName`（叶子名）与 `actualDepartmentPath`（完整路径，`null`=无） |

- **表单**：人员表单“基本信息”中紧随“编制单位”之后的“实际单位”一项，不必填；清空后保存即恢复在编在岗。
- **列表**：人员列表“编制单位”列仍显示编制全路径；当**实际单位已设置且与编制单位不同**时，在路径后追加灰色小标签“实际：某某单位”（取实际单位完整路径的末段），鼠标悬停可见完整路径。实际=编制或未设置时不显示。
- **详情**：详情弹窗自动并列展示“编制单位（完整路径）”与“实际单位（完整路径）”。

## 查询与筛选

- 筛选面板（驾驶证三项之后）新增：
  - **在岗情况**：`onDuty=yes`（在编在岗）/ `onDuty=no`（借岗在外）。
  - **实际单位**：`actualDepartmentId=<单位ID>`，按实际单位**精确匹配**（不含下级）。
- 下钻路由：`#personnel?onDuty=no`、`#personnel?actualDepartmentId=12` 会被识别并回填到筛选控件；非法值忽略。`includeDescendants` 仍只跟随 `departmentId`（编制单位）生效。

## 仪表盘

新增“实际在岗分布”维度（`groups.actualDuty`，仅统计设置了实际单位的人员，按实际单位完整路径的树序返回）：

- 不在默认布局中，也不会写进旧布局迁移；需要时通过“添加图表”自行加入，支持条形图/环形图/玫瑰图/树状图。
- 图表按“完整路径”展示，点击某行时前端按路径反查单位 ID，下钻到 `#personnel?actualDepartmentId=<ID>` 精确筛选；路径无法匹配单位树时不提供点击。

## 点名册“按实际单位排列”

- 点名册弹窗在身份标志区下方新增单个切换按钮“按实际单位排列”（默认**关闭**，每次打开重置，与标志一样不记忆）。
- 开启后本次下载请求追加 `actualUnit=true`，Excel 按人员的**实际在岗单位**分组排列；关闭时不发送该参数，仍按编制单位。身份标志、人员排序等其他选项与协议不变。

## 花名册

- 花名册字段清单动态新增“实际单位”列按钮，按需勾选导出（与其他字段一致，默认不选中）。
- “实际单位”列导出**完整路径**。
